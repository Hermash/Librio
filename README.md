## Опис проєкту

**Librio** — вебсервіс для читачів, який дозволяє створювати цифрову бібліотеку, відстежувати прогрес читання та вести читацький щоденник. Користувачі можуть формувати списки книг, зберігати нотатки, ділитися враженнями та отримувати персональні рекомендації.

---

## Основні функціональні можливості:

- Керування власною бібліотекою: додавання, редагування та видалення книг
- Зручний пошук та сортування книг у каталозі
- Перегляд докладної інформації про книгу: опис, автор, жанр, рейтинг
- Профіль користувача та відстеження прогресу читання
- Швидка та проста реєстрація й авторизація користувачів
- Контактна форма для зворотного зв'язку з адміністрацією

---

## Основні сторінки:

- **index.html** — головна сторінка, презентація сервісу, швидка реєстрація  
- **auth.html** — реєстрація та авторизація користувача  
- **library.html** — особиста бібліотека користувача  
- **catalog.html** — каталог книг та пошук (8 книг у каталозі)
- **profile.html** — профіль користувача зі статистикою та переходом у бібліотеку
- **book.html** — детальна інформація про книгу з описом, деталями та відгуками
- **about.html** — інформація про сервіс, місія, цінності й контактна форма
- **contacts.html** — контактна інформація, графік роботи та форма зворотного зв'язку

## Використані HTML-елементи та теги

### Семантичні елементи:
- `<header>`, `<nav>`, `<main>`, `<footer>` — структура сторінок
- `<section>`, `<article>`, `<aside>` — логічні блоки контенту

### Текстові елементи:
- `<h1>`, `<h2>`, `<h3>` — заголовки різних рівнів
- `<p>` — абзаци тексту
- `<ul>`, `<ol>`, `<li>` — списки (нумеровані та марковані)
- `<strong>` — виділення тексту

### Форми та елементи введення:
- `<form>` — форми реєстрації, пошуку, контактів
- `<input>` — поля для введення тексту, email, пароля, пошуку
- `<textarea>` — багаторядкове поле для повідомлень
- `<select>`, `<option>` — випадаючі списки
- `<button>` — кнопки відправки форм
- `<label>` — підписи до полів форм

### Медіа та посилання:
- `<img>` — зображення з обов'язковим атрибутом `alt`
- `<a>` — посилання з атрибутом `href`

### Інші елементи:
- `<div>` — контейнери для блоків
- `<span>` — рядкові елементи

## Використані технології CSS

### Базові технології

- **CSS3** — каскадні таблиці стилів для оформлення інтерфейсу
- **CSS Custom Properties (змінні)** — централізоване управління кольоровою палітрою
- **CSS Flexbox** — гнучка система макетування для навігації, футера та складних розташувань
- **CSS Grid** — двовимірна сітка для каталогу книг з автоматичною адаптацією
- **Media Queries** — адаптивний дизайн для різних розмірів екрану

### Організація стилів

- Модульна архітектура з розділенням на логічні файли
- Використання директиви @import для об'єднання модулів
- Семантичне найменування класів

### Адаптивність

- Mobile-first підхід до дизайну
- Breakpoint'и: 768px (мобільні), 900px (планшети)
- Адаптивне бургер-меню для мобільних пристроїв
- Responsive сітки з автоматичним переносом елементів

### Особливості реалізації

- Валідація форм з візуальним зворотним зв'язком
- Hover-ефекти та плавні переходи
- Тіні та заокруглення для сучасного вигляду
- Кросбраузерна сумісність (Chrome, Firefox, Edge, Safari)

## Додана JavaScript-функціональність

**Темна та світла тема**
   - Перемикач теми (`dark-theme`) зберігає вибір користувача у `localStorage`.
   - Тема автоматично відновлюється після перезавантаження сторінки.

**Підсвітка меню навігації**
   - Підсвітка пунктів меню при наведенні миші через JS-класи.

**Зміна розміру шрифту**
   - Відстеження клавіш `ArrowUp` та `ArrowDown`.
   - Збільшення або зменшення розміру шрифту для всіх основних елементів (`p`, `h1–h3`, `li`, `label`, `button`).

**Валідація контактних форм**
   - Заборона стандартної відправки форми (`event.preventDefault()`).
   - Перевірка полів:
     - Ім’я — мінімум 3 символи.
     - Email — містить `@` та домен.
     - Повідомлення — мінімум 10 символів.
   - При помилці підсвічується поле червоним, показується повідомлення під полем.
   - При успіху — очищається форма, відображається повідомлення "Форма успішно надіслана!" та дані виводяться у консолі.

**LocalStorage**
   - Збереження імені користувача після введення у форму.
   - Збереження вибраної теми сайту.

**Інші JS-функції**
   - Акордеон для прихованих жанрів.
   - Динамічна кнопка "Хочете дізнатись більше про нас".
   - Підрахунок поточної дати у футері.
   - Стилізація карток книг (заокруглення, фоновий колір, текст).

## Використані технології JavaScript

- **DOM** — доступ до елементів сторінки, зміна класів та стилів.
- **Events** — обробка кліків, наведень, подій клавіатури.
- **Validation** — клієнтська валідація форм із візуальним зворотним зв'язком.
- **LocalStorage** — збереження даних користувача (ім’я, тема сайту).
- **Dynamic Elements** — створення кнопок, зміна списків на сторінці, акордеон.
