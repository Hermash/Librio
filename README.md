## Опис проєкту

**Librio** — вебсервіс для читачів, який дозволяє створювати цифрову бібліотеку, відстежувати прогрес читання та вести читацький щоденник. Користувачі можуть формувати списки книг, зберігати нотатки, ділитися враженнями та отримувати персональні рекомендації.

## Основні функціональні можливості:

- Керування власною бібліотекою: додавання, редагування та видалення книг;
- Зручний пошук та сортування книг у каталозі;
- Перегляд докладної інформації про книгу: опис, автор, жанр, рейтинг;
- Налаштування профілю та відстеження прогресу читання;
- Швидка та проста реєстрація й авторизація користувачів.

## Основні сторінки:

- **index.html** — головна сторінка, презентація сервісу, швидка реєстрація  
- **auth.html** — реєстрація та авторизація користувача  
- **library.html** — особиста бібліотека користувача  
- **catalog.html** — каталог книг та пошук  
- **profile.html** — налаштування профілю та статистика  
- **book.html** — детальна інформація про книгу
